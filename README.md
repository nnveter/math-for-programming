# Математика для программирования: решения практик

Ноутбуки разложены по контрольным работам в соответствии с темами из курса.

| Папка | Темы КР | Ноутбуки |
|---|---|---|
| `КР1` | СЛАУ, собственные значения и векторы, комплексные числа | `МатПрог1` (Листок 1), `МатПрог2` (Листок 2) |
| `КР2` | Дифференциальные уравнения, численные решения ДУ | `МатПрог3` (Листок 3), `ДУ_Практика1`–`ДУ_Практика4`, `КР_2_2` |
| `КР3` | Вероятность, статистика | `МатПрог4` (Листок 4), `МатПрог5` (Листок 5) |

Темы КР 4 в курсе пока не объявлены, поэтому папки для неё нет.

Рисунки и GIF лежат в папке `fig` внутри каждой КР. `КР2/МатПрог3.ipynb` весит около 30 МБ из-за встроенных анимаций.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # в Linux и macOS: .venv/bin/pip
jupyter notebook
```
